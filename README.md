# CASIO 计算器(Android 复刻版)

用 Kotlin + Jetpack Compose 从零实现的一台**卡西欧 fx-991CN X**(中国版)功能复刻。
不是套壳、不是网页包装:从**词法/语法分析、精确有理数运算、符号求导、数值积分**
到**矩阵/向量/统计/基数模式、方程求解、错误定位**,全部自研,并且带一套
**889 条断言的引擎自测**(装机运行,结果写进 logcat)。

> 界面按键按真机排布,但**不是**逐像素复刻 —— 详见「已知差异」。

---

## 功能

### 计算模式(10 种)

| 模式 | 内容 |
|---|---|
| **计算** | 四则、乘方、阶乘、隐式乘号(`2x`、`3(x+1)`、`2sin(π/6)`)、39 个函数 |
| **方程/函数** | 一元一次~四次(二次给**精确根式**)、高次数值根、超越方程牛顿法、**2/3/4 元线性方程组**、SOLVE 求根、CALC 代入、TABLE 函数值表 |
| **不等式** | 1~4 次,四种关系,解以**区间形式**给出 |
| **比例** | `a:b = c:X` 与 `a:b = X:d` 两型 |
| **矩阵** | 4×4 上限、MatA~D + MatAns、Det/Trn/逆/单位阵/幂/Abs、矩阵编辑器;可写 `MatA*MatB` |
| **向量** | 2D/3D、VctA~D + VctAns、内积/叉积/夹角/单位向量;可写 `VctA·VctB` |
| **统计** | 单/双变量、28 个统计量、6 种回归、**正态分布 P/Q/R/'t**、表格式编辑器 + 频率列 |
| **基数** | DEC/HEX/BIN/OCT、32 位、二位补码、and/or/xor/xnor、Not/Neg |
| **常数/换算** | 40+ 科学常数(CODATA)、40+ 公制换算对 |
| **复数** | 复数模式指示与运算(见「已知差异」) |

### 引擎能力

- **精确有理数**:`Rational` 用 BigInteger + 连分数还原,二次方程给 `(1/2 + √5/2)` 这类精确根式
- **符号求导**:`d/dx x^2*sin(x)` 返回化简后的导函数表达式
- **高精度积分**:**Gauss-Legendre 自适应求积**(n=8/16/32 嵌套取差作误差估计),节点与权重由 Golub-Welsch 算法**运行时算出**,不抄常数表
- **数值求导**:中心差分 + Richardson 外推
- **求极限**(超出真机能力的新增功能):双侧/单侧/趋于无穷,Richardson 外推 + 收敛性判定,不收敛时**明确报「不存在」而不是给个数**
- **错误体系**:7 种错误类型 + **出错位置定位**(真机风格的 `^` 指示)
- **历史持久化**:重启后仍可翻阅之前算过的式子
- **精确显示**:Fix/Sci/Norm/ENG/分数/带分数/π/根式,数学输入下**分数与根号竖排绘制**

### 界面

- LCD 面板:指示符行(含 M / SHIFT / ALPHA / 复数标记)→ 输入行 → **竖排结果行** → 历史
- 数字键盘 / **标准 QWERTY 字母键盘**(「切换」键切换),SHIFT 联动大小写
- 函数抽屉、命令抽屉(所有 `:命令` 都有按钮入口,**不依赖系统键盘**)
- 计算结果**自动滚动**:新输出的顶端拉到显示区顶端;太短则把底端拉到显示区底端
- 积分/求导/极限是**可编辑块**,块内字段带标注、分隔不可删、光标按字段跳

## 引擎自测

自测**没有用单元测试框架**,而是自己写的一个断言收集器,装机启动时运行并把结果写进 logcat:

```bash
adb logcat -s CASIO_SELFTEST:I
```

预期输出:

```
=== 引擎自测开始 ===
通过 889 / 失败 0
全部用例通过 ✅
=== 引擎自测结束 ===
```

**为什么这样做**:这是从 Windows 版移植过来的项目,移植期需要在真机/模拟器上快速确认
引擎行为与原版一致。跑在应用启动路径上,任何回归会在**启动瞬间**暴露,而不是等用户点到某个功能。

自测覆盖:四则与优先级、精确有理数、方程与方程组、矩阵、向量、基数、统计、
微积分、常数与换算、错误定位、CALC/TABLE、历史编码……

    ├── Limit.kt                 # 求极限(新增功能)
    ├── MatExpr.kt / Math...     # 矩阵与向量表达式求值(独立求值器)
    ├── Stats.kt                 # 统计与正态分布
    ├── BaseN.kt / Ineq.kt       # 基数 / 不等式与比例
    ├── Constants.kt             # 科学常数与公制换算
    ├── TableCalc.kt             # CALC / TABLE
    ├── Fmt.kt / Display.kt      # 结果格式化 / 文本表格

## 设计上的几个取舍

1. **矩阵/向量走独立求值器**。主引擎的 `Node.eval` 返回 `Double`,为支持 `MatA*MatB`
   把它改成泛型值会动到已被数百条断言覆盖的核心。所以 `MatExpr` 是一个**独立的、
   只处理矩阵/向量表达式的小求值器**,纯数值表达式仍走原引擎、一行未改。

2. **积分规则运行时构造,不抄常数表**。第一版想按手册字面实现 (7,15) Gauss-Kronrod,
   但 Stieltjes 递推系数记错导致规则退化(节点重复、权重为负)。改用 Golub-Welsch
   构造 + 规则嵌套取差:**每一步都能验证**,不依赖记不准的系数。

3. **错误定位放在错误层,不动解析器**。`Token` 里原本没有位置信息;给 Lexer 加位置字段
   会动到核心,所以改成在错误层按错误类型推断位置(引擎显式给「位置 N」时优先采用)。

4. **历史用长度前缀编码**。算式里会出现冒号、逗号、`=` 等字符,用分隔符拼接必然错位。

## 已知差异与不足

- **不是逐像素复刻**。手册只给功能与操作,不给数值口径细节(如根式化简的具体规则、
  循环小数的判定边界)。没有真机对照,这些只能按手册示例近似。
- **科学常数用 CODATA 值**,不是从手册逐条抄录(手册常数表未逐页核对)。
  若与手册有差异,以手册为准。
- **横向(landscape)适配未做**。
- **复数模式**:有指示符与运算支持,但没有完整的 `CMPLX` 专用界面。
- **BASE-N 的值未接入表达式求值**(真机可在基数模式里做四则运算并保持进制)。
- 矩阵/向量的二元运算在编辑器里固定用「当前 + 下一个」配对,不如真机的 `Cc` 菜单直接。
